# AI-агентная система red teaming и контроль ответов LLM «ГигаЧат»

## Описание проекта

Проект представляет собой веб-приложение на базе **Streamlit** для автоматической оценки ответов языковой модели GigaChat на предмет безопасности и соответствия цензурным требованиям. Система выполняет:

- Чат с GigaChat.
- Классификацию ответов (хороший/плохой) с пояснением причины.
- Анализ токсичности через локальную модель Tinkoff.
- RAG  с использованием размеченного датасета и документа цензурных правил.
- Хранение истории диалогов в SQLite с поддержкой нескольких чатов.
- Экспорт данных в CSV.
